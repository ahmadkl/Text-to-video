# Text-to-Video — فيديو من نص

يحوّل نصًا إلى فيديو MP4: خلفيات متحركة، نص عربي أو إنجليزي، تعليق صوتي (اختياري)، وملف ترجمة `.srt`.
كل **فقرة = مشهد**، والسطر الأول إن بدأ بـ `# ` صار بطاقة العنوان.

> للحصول على فيديو **حقيقي بحركة وصوت** (مثل أفلام Veo) انظر قسم «فيديو حقيقي بـ Veo» أدناه. بقية الأوضاع تصنع نصًا متحركًا أو صورًا بحركة كاميرا.

## التشغيل من الجوال (بدون تثبيت شيء)

**الطريقة 1 — Issue (الأسهل):**
1. افتح تبويب **Issues** ← **New issue**.
2. اجعل العنوان يبدأ بكلمة `video` (مثل: `video قصة الفضاء`).
3. اكتب في النص قصتك: افصل المشاهد بسطر فارغ.
4. بعد دقائق يُضاف تعليق على الـ Issue برابط الفيديو.

**الطريقة 2 — Actions:**
**Actions ← Generate video ← Run workflow**، ثم اكتب النص في خانة `prompt` (افصل المشاهد بـ ` || `)، واختر الأبعاد والصوت.

الفيديو يظهر في **Releases** جاهزًا للتنزيل، وفي Artifacts داخل تشغيل الـ workflow.

> الـ Issue يعمل فقط إذا فتحه مالك المستودع.

## فيديو حقيقي بـ Veo: توليد تلقائي (مدفوع)

أضف في **Settings ← Secrets and variables ← Actions** السرّ `GEMINI_API_KEY` (مفتاح من Google AI Studio بحساب فيه فوترة). ثم **Actions ← Generate video ← Run workflow** واختر:
- `style = veo` و`aspect = 9:16` للفيديو العمودي،
- `max_clips = 3` للتجربة (نحو 24 ثانية فيديو)، أو `0` للقصة كلها،
- `dry_run = true` لمعرفة عدد اللقطات والتكلفة التقديرية دون صرف شيء.

يختار المشروع نموذج Veo المتاح لمفتاحك تلقائيًا (يفضّل المستقر على التجريبي، والأرخص `fast` ما لم تطلب غيره عبر `--veo-quality standard`). تُحاسَب كل لقطة حتى لو لم تعجبك، والنتائج تُخزَّن فلا تُدفع مرتين لنفس اللقطة عند إعادة التشغيل.

## الطريقة اليدوية: لقطات Google Flow + تجميع تلقائي

للحصول على فيديو بحركة وأصوات حقيقية (شخصيات تتكلم وتتحرك) يلزم نموذج توليد فيديو. المشروع يجهّز العمل كله ما عدا التوليد نفسه:

1. **حزمة اللقطات:** `python make_shots.py -f story.txt --aspect 9:16` (أو Actions ← **Make shot pack**، أو Issue عنوانه `shots ...` ونصه القصة). يقرأ القصة حتى لو كانت فقرات متصلة بلا أسطر، ويكتب `shots/shots.md`: وصف ثابت لكل شخصية، وأمر جاهز لكل لقطة (حتى 8 ثوانٍ) فيه المكان والتصوير والحوار بالعربية.
2. **التوليد:** انسخ أمر كل لقطة إلى Google Flow (Veo 3.1)، ولّد، ونزّل الفيديو باسم `shot_001.mp4` ثم `shot_002.mp4`…
3. **الرفع والتجميع:** ارفع المقاطع إلى مجلد `clips/`، ثم Actions ← **Assemble video**: يرتّبها ويوحّد أبعادها ويضيف الترجمة العربية ويخرج فيديو واحدًا في Releases.

حصة Flow المجانية صغيرة (عدد قليل من اللقطات يوميًا، بعلامة مائية)، فالفيلم الطويل يحتاج أيامًا أو اشتراكًا. وبديل مدفوع: Veo عبر Gemini API (نحو 0.05–0.12 دولار للثانية).

## وضع السيناريو: شخصيات وأصوات وحوار

إذا كان النص سيناريو، يكتشفه المشروع تلقائيًا (أو استعمل `--mode screenplay`) ويرسم **شخصيات** ويعطي كل واحدة **صوتًا مستقلًا** وتتحرك أفواهها مع الكلام:

```
المشهد 7
خارجي – جانب منزل علي – نهار

عبد الله جالس مع عامر وأبو عامر. علي يقف أمامهم.

علي:
السلام عليكم.

عبد الله (بصوت منخفض):
من أولها عم يعاند.
```

- `# عنوان` أو `المشهد N` ← بطاقة عنوان.
- سطر يبدأ بـ `داخلي` أو `خارجي` (أو `INT` / `EXT`) ← بطاقة مكان، وتحدد الخلفية (بيوت وسماء، أو غرفة). وكلمة `ليل` تجعلها ليلية.
- `الاسم:` ثم الكلام ← حوار. الشخصيات تُستخرج من أسماء المتحدثين، ومن جمل مثل "جالس **مع** عامر وأبو عامر" للصامتين.
- `الجميع:` ← تتحرك أفواه كل الشخصيات.
- الفقرات الأخرى ← وصف حركة يقرؤه راوٍ (`--no-narrator` لإيقافه). جملة مثل "ينهض علي وينصرف" تجعل الشخصية تخرج من المشهد.
- ما بين القوسين بعد الاسم يغيّر نبرة الصوت: همس، غضب، حزن.
- لتحديد الشخصيات بدقة أضف سطرًا: `الشخصيات: علي، سارة (أنثى)، أبو عامر (كبير)، سالم (طفل)`.

الأصوات من `edge-tts`: لهجة شامية وأصوات متنوعة للرجال والنساء، والجنس يُخمَّن من الاسم ويمكن تحديده في سطر الشخصيات.

## الوضع السينمائي: لقطات واقعية أو أنمي (الافتراضي للسيناريو)

بدل الرسومات البسيطة، يولّد المشروع **صورة بالذكاء الاصطناعي لكل لقطة**: لقطة قريبة للمتحدث في الحوار، ولقطة عامة للمكان في وصف الحركة. ثم يحرّك الكاميرا ببطء (زوم وتحريك)، ويضيف صوت كل شخصية والترجمة. هذا الأسلوب قريب من فيديوهات القصص المصوّرة بالذكاء الاصطناعي، **وليس تمثيلًا بحركة حقيقية**: الوجوه لا تتحرك أفواهها، والمشهد صور متتابعة.

- **المزود الافتراضي `pollinations`:** مجاني ولا يحتاج مفتاحًا.
- **جودة وثبات أعلى:** أنشئ مفتاحًا مجانيًا من Google AI Studio وأضفه في **Settings ← Secrets and variables ← Actions** باسم `GEMINI_API_KEY`، فيُستخدم تلقائيًا.
- **الأنمي:** اختر `look = anime` في تشغيل Actions، أو أضف في السيناريو سطرًا: `الأسلوب: anime movie still, ...`.
- **ثبات شكل الشخصية:** لكل شخصية وصف ثابت يُرسل مع كل لقطة. للتحكم في شكلها اكتب سطرًا بالإنجليزية في السيناريو:

```
الشخصية: علي = a Syrian man in his 40s, short black hair, light stubble, grey work shirt
الشخصية: أبو عامر = an elderly man with white keffiyeh and grey mustache
خارجي – جانب منزل علي – نهار | a quiet village lane with old stone houses, afternoon light
```

الأوصاف بالإنجليزية لأن مولّدات الصور تفهمها أفضل. إن لم تكتبها، يولّد المشروع وصفًا تلقائيًا من اسم الشخصية وعمرها وجنسها.
كل فيديو يخرج معه ملف `video_prompts.txt` فيه الوصف المستخدم لكل لقطة، لتعدّل عليه.

## إرسال الفيديو إلى تيليجرام (اختياري)

أضف في **Settings ← Secrets and variables ← Actions** السرّين `TELEGRAM_BOT_TOKEN` (من BotFather) و`TELEGRAM_CHAT_ID`، فيصلك كل فيديو جاهز على تيليجرام إضافة إلى Releases.

## التشغيل على جهازك

```bash
sudo apt install ffmpeg fonts-noto-core      # أو ما يعادلها
pip install -r requirements.txt
python make_video.py -f examples/scene7.txt -o output/video.mp4     # سيناريو (لقطات بالذكاء الاصطناعي)
python text_to_video.py -f examples/arabic.txt -o output/video.mp4  # نص متحرك فقط
```

أمثلة:

```bash
python text_to_video.py -t "مرحبا || هذا هو المشهد الثاني" --aspect 9:16
python text_to_video.py -f examples/english.txt --voice en-GB-RyanNeural
python text_to_video.py -f examples/arabic.txt --no-voice
```

| الخيار | الوصف |
|---|---|
| `--aspect` | `16:9` (افتراضي) أو `9:16` للجوال أو `1:1` |
| `--voice` | `auto` يختار صوتًا عربيًا أو إنجليزيًا حسب النص، أو اسم صوت مثل `ar-EG-SalmaNeural`، أو `none` |
| `--rate` | سرعة الصوت، مثل `-10%` أو `+15%` |
| `--min-scene` | أقل مدة للمشهد بالثواني (3 افتراضيًا) |
| `--max-chars` | الفقرة الأطول تُقسَّم إلى مشاهد |
| `--seed` | لتثبيت الألوان والحركة |

أصوات عربية: `ar-SA-HamedNeural`، `ar-SA-ZariyahNeural`، `ar-EG-SalmaNeural`، `ar-EG-ShakirNeural`.
القائمة الكاملة: `edge-tts --list-voices`.

## ملاحظات

- التعليق الصوتي يستخدم `edge-tts` ويحتاج اتصالًا بالإنترنت. إن فشل يُنتَج الفيديو بدون صوت مع تحذير.
- لخط عربي مخصص: ضع ملف `.ttf` داخل مجلد `fonts/` أو اضبط المتغير `FONT_PATH`.
- كل فيديو يُنتج أيضًا `video.srt` بالترجمة.
